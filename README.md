# WB Sales Telegram Bot

Telegram-бот для двух кабинетов Wildberries. Каждый час, в `XX:00` по Москве, бот отправляет **два отдельных сообщения** — по одному на каждый кабинет.

## Что считает

- **Заказано итого** — все заказы, оформленные за текущие сутки, включая заказы, которые позднее были отменены.
- **Выкуплено итого** — реальные продажи за текущие сутки. Возвраты не считаются.
- Ниже выводится разбивка **только по заказам**: `артикул продавца — количество`.
- Артикулы с нулём не выводятся.
- Отчёт накопительный: с `00:00` текущего дня до текущего момента.
- Часовой пояс расчёта: `Europe/Moscow`.

## Используемые методы Wildberries

Токен WB должен иметь доступ к категории **Статистика**.

- `GET https://statistics-api.wildberries.ru/api/v1/supplier/orders`
- `GET https://statistics-api.wildberries.ru/api/v1/supplier/sales`

Для текущего дня используется `dateFrom=YYYY-MM-DD&flag=1`.

> Важно: данные Statistics API обновляются не мгновенно (обычно примерно раз в 30 минут), поэтому цифры в почасовом сообщении могут немного отставать от интерфейса WB.

## Установка

Рекомендуется Python 3.11+.

```bash
python -m venv venv
```

Linux/macOS:

```bash
source venv/bin/activate
```

Windows:

```bat
venv\Scripts\activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

## Настройка

Скопируйте `.env.example` в `.env`:

```bash
cp .env.example .env
```

На Windows можно просто создать копию файла вручную.

Заполните:

```env
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_ID=...

WB_TOKEN_1=...
WB_NAME_1=СПб-ТТ

WB_TOKEN_2=...
WB_NAME_2=СПб-ТТ Групп
```

### Где взять TELEGRAM_CHAT_ID

1. Напишите своему боту любое сообщение.
2. В браузере откройте:
   `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
3. Найдите `chat.id`.

Если бот отправляет отчёты в группу, добавьте его в группу и укажите ID группы (обычно отрицательный).

## Запуск

```bash
python bot.py
```

После запуска бот работает через Telegram long polling.

## Команды

- `/start` — проверить, что бот работает.
- `/report` — получить оба отчёта вручную.

Доступ к командам ограничен `TELEGRAM_CHAT_ID` из `.env`.

## Формат сообщения

```text
Заказы за 16.09.2026
Кабинет: СПб-ТТ

Заказано итого: 47 шт.
Выкуплено итого: 31 шт.

ABC-001 — 12 шт.
ABC-002 — 8 шт.
ABC-003 — 5 шт.
ABC-004 — 22 шт.
```

Если заказов нет:

```text
Заказы за 16.09.2026
Кабинет: СПб-ТТ

Заказано итого: 0 шт.
Выкуплено итого: 0 шт.

Заказов по артикулам нет.
```

## Работа 24/7

Для постоянной работы запускайте на VPS/сервере через Docker, systemd, supervisor или аналогичный менеджер процессов. Бот сам планирует отправку в начале каждого часа.

## Замечание по лимитам WB API

У методов статистики строгие лимиты. В клиенте есть короткий кэш, чтобы ручная команда `/report`, запущенная сразу после автоматического отчёта, не вызвала лишний `429 Too Many Requests`.
